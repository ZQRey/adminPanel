# CYBER//HUD — Sci-Fi Personal Dashboard (Docker Deployment)

Веб-приложение персонального дашборда в стиле Sci-Fi HUD и концепции Hommar.
Готово к быстрому развертыванию на любом Linux/Windows-сервере с помощью Docker и Docker Compose.

---

## 🚀 Быстрый старт (Развертывание в Docker)

### 1. Клонирование / Перенос на сервер
Скопируйте папку проекта на ваш сервер.

### 2. Настройка переменных окружения (Опционально)
По умолчанию приложение уже настроено и готово к запуску на порту `80`.
При необходимости вы можете скопировать образец конфигурации:
```bash
cp .env.example .env
```
В файле `.env` можно изменить:
- `PORT` — внешний порт (по умолчанию `80`, можно указать `8080`, `3000` и т.д.)
- `SECRET_KEY` — секретный ключ для подписи JWT-токенов
- `FERNET_KEY` — 32-байтный ключ для шифрования учетных данных (AD/Proxmox/NUT)

### 3. Запуск контейнеров
Выполните команду в корневой папке проекта:
```bash
docker compose up -d --build
```

### 4. Вход в систему
Откройте в браузере:
- **`http://<IP_ВАШЕГО_СЕРВЕРА>`** (или порт, указанный в `PORT`)

**Учетная запись супер-администратора по умолчанию:**
- **Логин:** `admin`
- **Пароль:** `admin123`

## 📁 Структура хранилища и монтируемые тома (Volumes)

Контейнеры настроены так, чтобы данные сохранялись при перезапусках и обновлениях:

| Путь на хосте | Путь в контейнере | Назначение |
| :--- | :--- | :--- |
| `./data/` | `/app/data/` | База данных SQLite (`dashboard.db`) со всеми пользователями, панелями и настройками. |
| `./backend/plugins/` | `/app/plugins/` | Пользовательские Python-скрипты телеметрии. Добавляйте новые `.py` файлы прямо сюда без пересборки контейнера. |
| `./backend/static/` | `/app/static/` | Фоновое изображение `image_0.png` и статические ресурсы. |

## 🛠 Полезные команды управления

- **Просмотр логов в реальном времени:**
  ```bash
  docker compose logs -f
  ```
- **Просмотр логов только бэкенда:**
  ```bash
  docker compose logs -f backend
  ```
- **Перезапуск сервисов:**
  ```bash
  docker compose restart
  ```
- **Остановка сервисов:**
  ```bash
  docker compose down
  ```
- **Обновление после изменений в коде:**
  ```bash
  docker compose up -d --build
  ```

## 🔒 Безопасность и архитектура
- **Nginx Reverse Proxy**: Фронтенд собран в многоэтапном Dockerfile (Node.js -> Nginx Alpine). Nginx обслуживает SPA, кэширует статику и проксирует `/api/` и WebSocket `/ws/` на внутренний контейнер бэкенда.
- **Backend Proxy**: Клиентский браузер никогда не обращается к вашим гипервизорам (Proxmox) или ИБП (NUT) напрямую. Все запросы идут через бэкенд FastAPI.
- **Шифрование данных**: Пароли интеграций и токены API хранятся в БД в зашифрованном виде (Fernet AES).
- **Изолированный запуск плагинов**: Пользовательские скрипты в `./backend/plugins` выполняются в отдельных асинхронных подпроцессах с жестким тайм-аутом 4 секунды.
